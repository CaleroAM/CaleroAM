## `$ nix-env -qa --projects`

### 🧠 [Graphtyn](https://github.com/CaleroAM) `v0.10.x`
> **AI-Native Code Intelligence Platform & MCP Server**
* **Core:** Dual-graph (código + memoria), Tree-sitter AST parser, SQLite FTS + embeddings vectoriales.
* **Componentes:** CLI nativa, API en FastAPI, dashboard interactivo y servidor Model-Context Protocol (MCP).

### ⚽ [isac26](https://github.com/CaleroAM)
> **Sports Tactical Data Analytics (Club América & StatsBomb)**
* **Data Pipeline:** Cliente Python optimizado para 10+ endpoints de StatsBomb API con capa local de caché.
* **Producto:** Visualizador táctico interactivo con métricas avanzadas ($xG$, $OBV$) procesando más de 129 partidos profesionales.

### 🌾 [modIAceb](https://github.com/CaleroAM)
> **End-to-End MLOps Application for Crop Yield Estimation**
* **Stack:** React/Vite/TS + Django REST Framework + PostgreSQL + Redis/RQ para procesamiento geoespacial asíncrono.
* **MLOps:** Despliegue reproducible con Docker, versionado estricto de modelos (`TabPFN`) y pipelines auditables.

### 🎮 [TourMuseosPuebla](https://github.com/CaleroAM)
> **Clean Architecture & Real-Time Resilient Systems**
* **Arquitectura:** Núcleo de lógica pura en C#/.NET totalmente desacoplado de Unity bajo principios DDD / SOLID.
* **AI Resilience:** Enrutamiento dinámico multirregional para Google Vertex AI y parsers binarios ad-hoc para mitigar límites de API.
